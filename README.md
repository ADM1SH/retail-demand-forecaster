# HYGR Retail Demand Forecaster

A macro-to-micro predictive demand forecaster linking Malaysia's private consumption indicators (Economic Outlook 2027 Table 3.5), CPI inflation, and employment indicators to HYGR's 4-channel retail matrix (**Shopee MY, Shopee SG, TikTok MY, TikTok SG**).

## Installation & Running

```bash
pip install -r requirements.txt
pytest -v
streamlit run app.py
```
